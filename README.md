# ECO NEXA GAMES — Guardiões da Ilha

Website cinematográfico e interativo para o projeto acadêmico fictício Eco Nexa Games.

## Estrutura
- `index.html` — experiência completa e conteúdo
- `styles.css` — direção visual, HUD, responsividade e animações
- `script.js` — partículas, navegação, contadores, equipe, guardiões, mapa, missões, NEX, modais e interações
- `assets/` — pasta reservada para fotos reais e outros ativos

## Fotos reais da equipe
Não foram inventadas fotos. Para substituir os placeholders, você pode inserir imagens e adaptar os blocos `.portrait-placeholder` e `.modal-portrait` no HTML/CSS.

## Uso
Abra `index.html` diretamente em um navegador moderno. O projeto não depende de backend.
