# ECONEXA: GUARDIÕES DA ILHA

Experiência web interativa feita com HTML5, CSS3 e JavaScript puro.

## Estrutura

- `index.html`
- `style.css`
- `script.js`
- `assets/personagens/`
- `assets/viloes/`
- `assets/outros/`

## Como executar

Abra `index.html` diretamente no navegador.

Não há backend, banco de dados, React, Vue ou Angular.

## Imagens fornecidas

As imagens enviadas foram incorporadas ao projeto:

- `assets/outros/logo-econexa.jpeg`
- `assets/outros/logo-guardioes-da-ilha.jpeg`
- `assets/personagens/guardioes-poster.jpeg`
- `assets/viloes/viloes-poster.jpeg`
- crops individuais de Luna, Íris, Andrew, Theo, Valtor, Stormy, Ogron e Tritanus.

Os crops individuais foram feitos a partir dos pôsteres enviados para permitir uso nos cards e modais.

## Sistemas implementados

- navegação responsiva
- menu mobile
- HUD e progressão
- missões e recompensas
- mapa interativo
- fichas de Guardiões e Vilões
- combate Luna vs Valtor
- NEX com análise dinâmica
- quiz de 10 situações com embaralhamento
- pontuação, combo, ranking e conquista
- ECO BREAKER em Canvas
- COLETA ECOLÓGICA
- NEX MEMORY
- conquistas
- educação ambiental
- central de progresso
- efeitos, partículas, modais, notificações e Web Audio opcional
